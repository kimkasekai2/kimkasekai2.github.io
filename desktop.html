Windows 12 Versi Web

Ikhtisar

  Windows 12 Versi Web adalah sebuah proyek open source karya asli Tan Jingyuan yang menggunakan HTML, CSS, dan JavaScript untuk mensimulasikan serta mengembangkan sistem operasi lewat web.

  Proyek ini telah diterbitkan di GitHub,Klik di sini untuk melihat。

  Jika Anda memiliki saran atau pendapat tentang proyek ini, silakan di GitHubkirim issues, masalah Anda akan diselesaikan sesegera mungkin.

  Penulis asli Xingyuan; klik untukSelengkapnya。

Keterangan open source

  Proyek ini adalah proyek open source dan menggunakan lisensi open source EPL v2.0. Lisensi open source adalah kontrak yang mengikat secara hukum; mohon patuhi lisensinya dengan kesadaran sendiri dan hormati kerja keras orang lain.

  Sesuai lisensi, Anda boleh menyebarkan, mendistribusikan, memodifikasi, dan menerbitkan ulang proyek ini, termasuk untuk keperluan pribadi maupun komersial.

  namun Anda wajib mencantumkan asal kode sumbernya,termasuk penulis, tautan proyek, dll., wajib open source dengan lisensi yang sama.

  Jika kode sumber proyek ini diterbitkan sebagai bagian dari proyek bersama kode sumber privat Anda, Anda boleh memakai lisensi lain,namun Anda harus menyatakan bagian konten EPL dan menyatakan bahwa bagian itu tetap mengikuti protokol EPL。

  Yang tidak menambahkan atau memodifikasi berdasarkan proyek ini dan hanya merujuk kode sumbernya tidak wajib open source, namun tetap hanya untuk tujuan belajar.
